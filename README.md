# Конвертер старых мер

Приложение для перевода старинных русских единиц измерения (аршин, сажень, верста, пуд, фунт, золотник) в современные метрические единицы (метры, килограммы).

2. Активируйте виртуальное окружение:
- Windows: `venv\Scripts\activate`
- macOS/Linux: `source venv/bin/activate`
3. Установите зависимости:
4. Запустите приложение:
## Использование

- Выберите единицу измерения из списка "Из:" (например, "аршин").
- Выберите целевую единицу из списка "В:" (например, "метры").
- Введите значение в поле "Значение:".
- Нажмите кнопку "Перевести".
- Результат появится ниже.
- Вы можете загрузить иконку или изображение, нажав кнопку "Загрузить иконку".

## Структура проекта

- `main.py` – точка входа, настройка QApplication.
- `ui_main.py` – интерфейс и логика обработки событий.
- `database.py` – работа с SQLite (сохранение истории конвертаций).

## Требования

- Python 3.6+
- PyQt5
- Pillow

## Логирование

Приложение автоматически записывает логи в файл `app.log`. В лог попадают:
- Конвертация единиц
- Загрузка изображений
- Ошибки
- Закрытие приложения

Логи выводятся в консоль и сохраняются в файл для отладки.
